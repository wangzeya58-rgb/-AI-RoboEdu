# 课程归属与发布

## 业务规则

- 创建者 ID 沿用正式 `courses.teacher_id`；管理员编辑不会更改创建者。
- `creator_role` 记录创建时的角色，不使用当前编辑者或前端角色决定公开范围。
- 管理员课程新建为公共范围的草稿，显式“发布为公共课程”后所有正式学生可学习，无需入班。
- 教师课程新建为班级范围的草稿，只能发布到创建教师自己的班级；学生必须为 approved 成员。
- 教师仅管理自己的课程；管理员可管理全部正式课程，但不能把教师课程转成公共课程。
- 取消公共发布后回到草稿；班级课程撤销最后一个发布关联后回到草稿。
- 课程中心合并公共课与授权班级课，一门课程只列一次并标注来源。
- 详情、章节、AI 和学习进度均复用服务端实时权限检查；历史进度不删除，但失去权限后不能读写。
- 当前公共课程面向已登录学生，不新增匿名或 Demo 读取正式课程的权限。

## 正式迁移

- `0004_course_publication_scope.sql`：新增角色快照与发布范围；从可靠的现有创建者关系补齐角色。历史课程全部保留 legacy 范围，不自动公开，不改创建者或班级关联。
- `0005_normalize_legacy_publication.sql`：旧代码只写入班级关联而不更新 draft。对 legacy 且已有关联的旧草稿修正为 published，授权仍限原班级，不新增关联、不公开；无关联的草稿不变。
- legacy 课程保留原班级授权；未知归属须管理员确认后才能新增发布。确认本身不改变范围、状态或班级关联。
- 新式班级发布只认可创建教师的班级；历史关联记录保留，不会让其他教师班级绕过新规则。
- 本轮在已确认的本地 ai_roboedu_dev 完成 0004/0005；未操作生产数据库。备份在专用开发 PostgreSQL 容器 `/tmp/ai-roboedu-before-publication.dump`。
- 后续环境应先备份、审查数据库身份及迁移历史，再加载对应环境变量执行 `pnpm run db:migrate`。不使用 push/reset，不重写已执行迁移。

## API

- `GET /api/v1/courses`：教师本人或管理员管理列表。
- `GET /api/v1/courses?view=readable`：教学资源读取列表；教师为自己的课程（含草稿）及已发布公共课程，管理员全部，学生为公共课及获授权班级课。公共课只读不赋予教师管理权。
- `GET /api/v1/courses/available`：正式学生可学习课程及来源。
- `POST/DELETE /api/v1/courses/[id]/publication`：管理员公共发布/取消。
- `POST/DELETE /api/v1/courses/[id]/classes`：按 classId 发布/取消班级关联。
- `POST /api/v1/courses/[id]/ownership`：管理员确认未知旧课程创建者，只接受正式教师/管理员用户 ID；角色由数据库确认。
- 原详情、章节、AI、进度路径不变。未认证 401、无权限 403、资源不存在 404、参数非法 400、冲突 409。

## Demo

- 继续使用原 IndexedDB，不清库、不自动迁移；新增本地创建者、状态与班级发布字段。
- 旧记录没有归属时不猜测，不在学生列表显示。管理员可在课程详情确认实际 Demo 创建者；确认后仍为草稿，需要另行发布。
- Demo 教师仅管理本人课程；管理员可管理本地课程，但编辑不改变原归属。
- 本地学生列表、直达播放器和 Blob 文件读取都会检查发布与 approved 成员关系；移除成员、取消发布、切换身份后重新校验并释放失效预览 URL。
- 通过本页事件、跨标签通知、窗口焦点及定时权限检查更新；已下载到设备的文件不能追溯撤回。
- Demo 仅供同一浏览器演示，不构成可信权限系统。正式账号不读取本地课程；Demo 不请求正式课程/班级业务 API。
- 正式附件上传、文件存储及 PPT/Word 正文解析尚未接入，本轮不把 Demo 文件当作正式服务器资源。
